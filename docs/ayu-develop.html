Design decisions

Decision Rationale Tradeoff Evidence
Keep host command routing separate from gateway connectivity. External gateway plugins implement venue protocols while the host shares event and OMS infrastructure. Source-backed gateway routing does not validate any particular venue service. MainEngine.init (L94) / MainEngine.add_gateway (L120) / MainEngine.send_order (L265) / BaseGateway.on_event (L92) / BaseGateway.on_order (L115)
Match historical alpha orders before the strategy on_bars callback. Previously queued limit orders are evaluated on the current bar before new decisions. Equity OHLC matching and price-limit assumptions constrain fill realism. BacktestingEngine.run_backtesting (L171) / BacktestingEngine.new_bars (L607) / BacktestingEngine.cross_order (L648)

Strengths and limits

Strengths

  • Host events, order cache and gateway routing have clear implementation boundaries. MainEngine.init (L94) / MainEngine.add_gateway (L120) / MainEngine.send_order (L265) / EventEngine._process (L68) / OmsEngine.init (L380) / OmsEngine.process_order_event (L420) / BaseGateway.on_event (L92) / BaseGateway.on_order (L115)
  • The current repository includes a native alpha backtester, separate from external CTA applications. BacktestingEngine.run_backtesting (L171) / BacktestingEngine.new_bars (L607) / BacktestingEngine.cross_order (L648)

Limitations

  • External CTA, spread, options and gateway plugins must not be described as bundled core implementation without inspecting their packages. MainEngine.init (L94) / MainEngine.add_gateway (L120) / MainEngine.send_order (L265)
